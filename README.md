# LINE公式アカウント連動 予約システム (LINE Reservation System)

LINE公式アカウントから24時間空き状況を確認し、希望メニューを選択して即時予約ができるフルスタックWeb予約システムです。

---

## 🌟 主な特徴と要件対応

### 1. お客も店舗側も予約の空き状況が確認可能（要件①）
- **お客側**:
  - メニュー選択後、カレンダー上で「○ 空きあり」「△ 残りわずか」「✕ 満枠」「休業日」を月間表示。
  - 日付を選ぶと、選択したメニューの所要時間（例: 90分）が確保できる時間枠スロット（10:00, 10:30...）のみが予約可能として一覧表示。
  - 過去の時間帯や営業時間外、満枠スロットの重複予約を確実に防止。
- **店舗側（管理画面）**:
  - 日別の予約・空き状況タイムラインモニターで、どの時間帯に誰の予約が何枠入り、どこが空いているかをリアルタイムに把握。
  - 空いているスロットをクリックして電話・店頭予約をその場で直接確保できる「手動予約登録」機能。
  - 確定・来店済み・キャンセルのステータス管理。

### 2. どのメニューで予約を取るか自由に設定可能（要件②）
- **店舗側（メニュー管理）**:
  - メニュー名、カテゴリ、料金（税込）、所要時間（分単位: 15〜180分など自由指定）、説明文、予約受付中/停止中の切り替え、追加・編集・削除をすべてGUIで完結。
- **お客側**:
  - 店舗が登録したメニューから希望のものを選択（複数選択・セット可能）。
  - 合計金額および合計所要時間がリアルタイムに算出され、その所要時間に応じた空き枠のみが選択可能に。

### 3. LINE公式アカウントで動かせる設計（要件③）
- **LIFF (LINE Front-end Framework) 完全対応**:
  - LINEアプリ内のトーク画面・リッチメニューからワンタップで開くWebアプリ。
  - LINEアカウントの表示名・プロフィール画像を自動連携。
  - 予約完了時に自身のLINEトークへ予約内容をワンタップ送信。
- **LINE Messaging API 連携**:
  - 予約完了時のLINEプッシュ通知（Flex Message対応）。
  - LINEトークでの自動応答・予約誘導Webhookエンドポイント（`/api/line/webhook`）。
- **ローカルテスト・シミュレーター搭載**:
  - LINE Developers登録前やPCブラウザでも、「LINE連携を疑似体験」ボタンで即座に動作テスト可能。

## 🚀 起動方法

### 1. 依存パッケージのインストール（初回のみ）
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
起動後、ブラウザで以下のURLを開きます：
- **お客様用 予約画面**: [http://localhost:3000](http://localhost:3000)
- **店舗側 管理ポータル**: [http://localhost:3000/admin](http://localhost:3000/admin)
  - 予約・空き状況ボード: `/admin`
  - メニュー設定: `/admin/menus`
  - 店舗・LINE設定: `/admin/settings`
  - LINE連携ガイド: `/admin/line-setup`

## 📱 LINE公式アカウント連携の流れ

1. **[LINE Developers](https://developers.line.biz/)** にログイン
2. プロバイダー配下に「Messaging API」チャネルを作成
3. 「LIFF」タブで新規LIFFアプリを作成し、エンドポイントURLに本システムのURL（例: `https://your-domain.vercel.app/`）を設定
4. 発行された `LIFF ID`、`Channel Access Token`、`Channel Secret` を本システムの店舗設定画面（`/admin/settings`）に入力
5. LINE Official Account Managerのリッチメニューに `https://liff.line.me/あなたのLIFF_ID` を設定して完了！

詳細な手順は店舗管理画面の **[LINE連携ガイド](/admin/line-setup)** からいつでもご確認いただけます。
